# 🎯 Problem Statement

> **How might we build a consent-based, secure, and privacy-preserving migrant tracking capability within eShram that enables location updates, migration heatmaps, predictive movement models, and simplified check-in mechanisms to better inform welfare delivery for migrant workers?**

---

# 🌍 Overview

**PravasiShram AI** is a **consent-driven migration intelligence prototype** designed to demonstrate how voluntary migration events can be transformed into privacy-conscious planning intelligence.

The concept focuses on:

- 👷 Simple migrant-worker check-ins
- 🎙️ Speech-based migration input
- 📍 Origin → destination extraction
- 🔐 Consent and data minimisation
- 🗺️ Migration corridor intelligence
- 📊 Aggregated migration insights
- 🔮 Predictive planning signals
- 🏛️ Authority decision support
- 🌐 Multilingual and low-data access

> **Track the migration event, not the person.**

Instead of continuously tracking a worker's location, the prototype captures a **voluntary migration event** and demonstrates how aggregated information could support welfare planning.

---

# 🚨 The Problem

Migrant workers may move between districts and states based on employment opportunities.

This creates an important planning challenge:

| **Challenge** | **Planning Difficulty** |
|---|---|
| 📍 Changing worker locations | Difficult to understand current migration patterns |
| 🔄 Inter-state migration | Welfare demand can shift across regions |
| 🏭 Employment-linked movement | Labour corridors can change over time |
| 📊 Fragmented information | Difficult to identify larger movement patterns |
| 🔐 Privacy concerns | Continuous personal tracking can create privacy and security risks |
| 📶 Limited digital access | Not every worker has reliable high-speed connectivity |

The key question is:

> **How can authorities understand migration patterns without turning a worker's phone into a continuous GPS beacon?**
